# docs/

docs/ には 3 種類の文書を置きます。種類ごとに、書く人・書くタイミング・書き換えてよいかが決まっています。施策ごとの記録は、コミット・scores.tsv・持ち越しの issue（CLAUDE.md の issue の決まり）で足りるので、施策ごとの文書は書きません。

## 種類

- 生きた文書：kit/（道具ごとの手引き）と flow/（場面ごとの手順）。リポジトリ直下の README.md と CLAUDE.md、.claude/skills/ のスキルも同じ扱いにする。
  - 道具や手順を変えたら、その変更と同じコミットで書き換える。
  - 書くのは変更したセッション自身で、main に直接コミットする。
- 積み上げる文書：overview/・retro/。
  - 書き換えず、新しい番号の文書を足す。差分がそのまま履歴になり、後から時系列で読めるようにするため。
  - 書くのはサブエージェント doc-writer で、docs ブランチにコミットする。返ったら、操作役が `make docs-merge` で main に取り込む。
  - design/・results/ は以前の施策の記録で、今は新しく書かない（既存の文書は残す）。
- 記録：scores.tsv。
  - `make bench`・`make score`・`make portal` が追記し、その場でコミットする。手で書き換えない。

## 生きた文書

### kit/

- 道具（make のターゲットのまとまり）1 つにつき 1 枚にする。ファイル名は道具の名前にする（例：bench.md）。
- 節は「役割・いつ使うか・動かし方・確かめ方・更新のしかた」の 5 つに固定する。
- 「動かし方」は、スクリプト冒頭のコメントと make help を指すだけにして、引数の説明を写さない。
- ほかの文書はリンクにせず、パスで書く。リンクで辿る入口は README.md の目次だけにする。
- 道具を足したら、README.md の目次にリンクを足す。make lint が漏れとリンク切れを見つける。

### flow/

- 道具をまたぐ手順だけを置く（first-time・resume・contest）。
- 施策 1 回の流れは .claude/skills/isu-ops/SKILL.md が正とし、flow/ には写さない。

## 積み上げる文書

### ディレクトリ

- `overview/` は全体像の資料（仕様メモ）を置く。調査役か人間が指示した時点のスナップショットとして作る。画像（画面のスクリーンショットなど）は、文書と同じ名前のフォルダ `overview/NNN_<スラッグ>/` に置き、本文から参照する（主な画面だけ、多くて 10 枚、幅 1280px 程度の PNG）。
- `retro/` は振り返りを置く。人間が指示した時点で作る。

### ファイル名

- `NNN_<英小文字のスラッグ>.md` の形にする。例：`002_after-memory-cache.md`。
- `NNN` は、ディレクトリごとの最大の番号に 1 を足す。

### 各文書に書くこと

すべての文書の冒頭に、書いた日時と基準のコミット（短い SHA）を書く。

#### overview/

- 採点の仕組みを書く：スコアの式、負荷が増える条件、減点、検証の条件（再起動の後・整合性・時間の制約）。
- 業務ドメイン、システム構成、コードの構成、エンドポイント、データモデル、主な処理の流れを書く。
- その時点で入っている施策と、スコアの推移を書く。
- 前のスナップショットからの変化を、冒頭に短くまとめる。

#### retro/

- やったことと効果を、スコアと一緒に時系列で並べる。材料は git log・scores.tsv・issue。
- 的確だったアプローチと、うまくいかなかったアプローチを書く。
- 次に活かすことを書く。キットへの気付きは、isucon-kit の issue にもする。

## 記録（scores.tsv）

- 列は time（手元の時刻の YYYYmmdd-HHMMSS）・rev（deploy 済みのコミット）・pass・score・memo・expect（make bench の `E=`）・fail（失敗したリクエストの件数。分からなければ空）。
- retro からは、該当する行をそのまま引く。

## 書き方

- 日本語の「です・ます」調で、一文を短く区切る。
- 推測は推測と書き、計測した値とは分けて書く。
- 太字などの装飾は使わない。図は Mermaid で描く。
- ファイル名・識別子・コマンドは、コードの表記のまま書く。
